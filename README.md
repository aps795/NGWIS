## Overview

Official digital identity and administrative portal for **New Global Wisdom International School**, an English-medium, co-educational institution in Saidpur, Ghazipur, Uttar Pradesh.

Designed with an academic institutional aesthetic, modern responsive layout, full adherence to factual accuracy, and an integrated in-browser CMS for school administrators.

---

## Key Features

- **Institutional Design System**: Deep Navy Blue (`#0B2545`), Academic Royal Blue (`#134074`), and Heritage Gold (`#D4AF37`) palette with classical serif typography (`Playfair Display`, `Cinzel`) and clean sans-serif body.
- **Strict Factual Authenticity**: Zero unverified CBSE/ICSE affiliations, fabricated rankings, or fake pass percentages. Transparent administrative placeholders are provided for leadership names and contact channels until officially verified.
- **Comprehensive Institutional Pages**:
  1. **Home**: Hero section with authentic campus feel, quick info strip (5 pillars), educational philosophy, Principal's message, 6 core feature cards, facilities preview, extracurricular activities, live circulars, upcoming events, Facebook connection card, and verified parent reviews showcase.
  2. **About Us**: Educational background, vision, mission, and the 6 foundational values (Education, Discipline, Excellence, Character, Growth, Future).
  3. **Academics**: Foundational, Primary, and Upper-Primary curriculum stages, key subjects, teaching methodology, and downloadable academic document modal.
  4. **Facilities**: Interactive category filters (Classrooms, Library, Playground, Sports, Computer Lab, RO Water, CCTV Safety, Activity Areas).
  5. **Activities & Sports**: Athletic competitions, morning assembly, yoga, cultural arts, debates, and annual festival schedule.
  6. **Photo Gallery**: Category filtering with an accessible, keyboard-navigable full-screen Lightbox viewer (ESC, Arrow keys).
  7. **Admissions**: 5-stage roadmap, documentation checklist, and interactive Admission Enquiry Form with immediate reference ID generation and Admin CMS sync.
  8. **Notice Board**: Searchable and filterable official school circulars with modal reader and print capability.
  9. **Contact Us**: Official address in Bhujehuan, Sauna, Saidpur, Ghazipur, interactive contact form, office timings, and embedded Saidpur Google Map frame.
  10. **Admin Dashboard / CMS (`#admin`)**: Non-technical management desk for school staff to view/export incoming admission enquiries to CSV, publish notices, add events, manage gallery photos, post testimonials, and update school contact placeholders.
- **SEO & Accessibility**:
  - Schema.org `School` / `EducationalOrganization` structured data JSON-LD.
  - OpenGraph social cards and canonical meta tags.
  - `robots.txt` and `sitemap.xml`.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8
- **Styling**: Tailwind CSS 3
- **Icons**: Lucide React + Custom SVG School Crest
- **State & Storage**: React Context + Browser `localStorage` persistence

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
